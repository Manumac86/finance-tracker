## 1. Introduction

- **Financial Health Score**: Real-time assessment of your financial wellness

### System Requirements

- Modern web browser (Chrome, Firefox, Safari, Edge)
- Internet connection
- JavaScript enabled

Use the dropdown selector to filter data by:

## 4. Managing Transactions

### Adding a Transaction

#### Method 1: Quick Add Button
1. Click the "+" button in Quick Actions
2. Select "Add Transaction"
3. Fill in the transaction details:
   - **Transaction Name**: Descriptive title
   - **Type**: Income or Expense
   - **Amount**: Transaction value
   - **Category**: Select from predefined categories
   - **Date**: When the transaction occurred
   - **Description**: Optional notes

4. Click "Save" to record the transaction

#### Method 2: Voice Input (Mobile)
1. Tap the microphone icon in the transaction form
2. Speak your transaction details
3. Review and confirm the parsed information

#### Method 3: Bulk Import
1. Navigate to Transactions page
2. Click "Bulk Import"
3. Choose import method:
   - **CSV Upload**: Upload bank statements
   - **Quick Text Entry**: Paste multiple transactions
   - **Manual Entry**: Add multiple transactions in a grid

### Viewing Transactions

The Transactions page provides:
- **Search Bar**: Find transactions by name or description
- **Filters**:
  - By Type (Income/Expense)
  - By Category
  - By Date Range
- **Sort Options**:
  - Date (Newest/Oldest)
  - Amount (Highest/Lowest)
  - Name (A-Z)

### Editing Transactions

1. Click on any transaction card
2. Select "Edit" from the menu
3. Modify the desired fields
4. Save changes

### Deleting Transactions

1. Click on the transaction card
2. Select "Delete"
3. Confirm the deletion

**Note**: Deleted transactions are soft-deleted and can be recovered by contacting support.

## 5. Budget Management

### Creating a Budget

1. Navigate to Budgets section
2. Click "Create Budget"
3. Complete the three-step process:

#### Step 1: Basic Information
- **Budget Name**: e.g., "Monthly Groceries"
- **Description**: Optional details
- **Budget Type**:
  - Category Budget: For specific spending categories
  - Total Budget: Overall spending limit
  - Custom Budget: Flexible rules

#### Step 2: Period & Amount
- **Budget Amount**: Your spending limit
- **Period**: Weekly, Monthly, Quarterly, or Yearly
- **Start Date**: When budget tracking begins
- **End Date**: Optional custom end date

#### Step 3: Alerts & Settings
- **Enable Budget Alerts**: Get notifications
- **Alert Threshold**: Percentage for warnings (e.g., 80%)
- **Alert When Over Budget**: Immediate notifications
- **Rollover Settings**: Handle surplus/deficit

### Monitoring Budgets

Each budget card displays:
- **Progress Bar**: Visual spending indicator
- **Amount Spent**: Current spending
- **Remaining**: Available budget
- **Status Indicators**:
  - Green: On Track
  - Yellow: Warning (approaching limit)
  - Red: Over Budget

### Budget Alerts

Receive notifications when:
- Reaching alert threshold (e.g., 80% spent)
- Exceeding budget limits
- Budget period is ending

Access alerts through:
- Dashboard notifications
- Budget Alerts panel
- Email notifications (if enabled)

## 9. Troubleshooting

### Common Issues and Solutions

#### Balance Appears Incorrect
- **Check**: All transactions are categorized correctly
- **Verify**: Income is marked as income, expenses as expenses
- **Review**: Date filters aren't excluding transactions
- **Action**: Refresh the page or clear cache

#### Charts Not Displaying
- **Ensure**: JavaScript is enabled
- **Check**: Browser is up to date
- **Try**: Different browser or incognito mode
- **Clear**: Browser cache and cookies

#### Transactions Not Saving
- **Verify**: All required fields are filled
- **Check**: Internet connection is stable
- **Ensure**: Amount is a valid number
- **Try**: Logging out and back in

#### Budget Alerts Not Working
- **Confirm**: Alerts are enabled in budget settings
- **Check**: Alert threshold is set appropriately
- **Verify**: Email notifications aren't in spam
- **Update**: Notification preferences in settings

### Data Recovery

If you accidentally delete data:
1. Check the "Recently Deleted" section (if available)
2. Contact support within 30 days
3. Provide transaction/budget/goal details

### Performance Issues

For slow performance:
1. Clear browser cache
2. Disable browser extensions
3. Close unnecessary tabs
4. Use a modern browser
5. Check internet connection speed

## 10. Frequently Asked Questions

### General Questions

**Q: Is my financial data secure?**
A: Yes, FinTrack uses bank-level encryption and secure authentication through Clerk. Your data is encrypted both in transit and at rest.

**Q: Can I export my data?**
A: Yes, you can export transactions, budgets, and reports in CSV format from the Reports section.

**Q: Is there a mobile app?**
A: FinTrack is a Progressive Web App (PWA) that works perfectly on mobile browsers and can be installed on your device for app-like experience.

### Transaction Questions

**Q: Can I categorize transactions automatically?**
A: Currently, you must select categories manually. Automatic categorization is planned for Phase 2.

**Q: How far back can I add transactions?**
A: You can add transactions for any date. We recommend keeping records for at least the current tax year.

**Q: Can I add recurring transactions?**
A: Recurring transaction functionality is planned for Phase 2. Currently, you need to add each transaction individually.

### Budget Questions

**Q: What happens when a budget period ends?**
A: Budgets automatically reset for the new period. If rollover is enabled, surplus or deficit carries forward.

**Q: Can I have multiple budgets for the same category?**
A: Yes, you can create multiple budgets with different periods or amounts for the same category.

**Q: How do I pause a budget?**
A: Edit the budget and set the end date to today, or delete it. Pausing functionality is coming in Phase 2.

### Goal Questions

**Q: Can I have multiple goals of the same type?**
A: Yes, you can create unlimited goals of any type.

**Q: What happens when I achieve a goal?**
A: The goal is marked as achieved with a celebration animation. You can keep it for reference or delete it.

**Q: Can I edit a goal after creation?**
A: Yes, all goal parameters can be edited except the type.

### Technical Questions

**Q: Which browsers are supported?**
A: Chrome (88+), Firefox (78+), Safari (14+), Edge (88+)

**Q: Does FinTrack work offline?**
A: Limited offline viewing is available. Full functionality requires internet connection.

**Q: How often is data synchronized?**
A: Data syncs in real-time when connected. Offline changes sync when connection is restored.
